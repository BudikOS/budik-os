# Security policy

Please do not report security vulnerabilities through public issues.

Use GitHub's private vulnerability reporting instead: go to the **Security** tab of this repository and click **Report a vulnerability**. Include the affected build, the device and steps to reproduce.

We will confirm the report within a few days and keep you updated until the fix is released. Credit is given in the release notes unless you prefer to stay anonymous.

Vulnerabilities in upstream code (AOSP, GrapheneOS, the Linux kernel) should also be reported to the upstream project.
